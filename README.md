# 📖 Axé Digital

### A tecnologia a serviço da tradição.

Aplicativo PWA desenvolvido para facilitar a consulta de Pontos Cantados durante as giras, proporcionando uma pesquisa rápida, intuitiva e totalmente offline.

---

## 🎯 Objetivo

O Axé Digital nasceu da necessidade de substituir a busca manual em apostilas PDF por uma experiência moderna, rápida e organizada.

O projeto busca preservar a tradição, respeitando a estrutura da apostila do CEUG e tornando o acesso aos Pontos Cantados mais simples durante as giras.

---

## ✨ Funcionalidades

- 🔎 Pesquisa Inteligente
- 📖 Consulta por categorias
- ⭐ Favoritos
- 📅 Gira de Hoje
- 🌙 Modo Escuro
- 📱 Instalação como aplicativo (PWA)
- ⚡ Funcionamento Offline
- 🔍 Busca por trecho do ponto
